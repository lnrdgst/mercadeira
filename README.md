# Mercadeira

API backend do Mercadeira, uma aplicação colaborativa para criação e
acompanhamento de listas de compras entre membros de uma família.

## Tecnologias

- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- PostgreSQL
- Flyway
- Maven

## Estrutura do projeto
